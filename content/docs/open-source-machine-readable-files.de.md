# Die besten Open-Source-Tools für llms.txt im Vergleich

Maschinenlesbare Indexdateien wie `/llms.txt` und `/llms-full.txt` bilden die Grundlage, damit autonome KI-Agents und LLMs Dokumentationen und Kerninhalte ohne clientseitigen JavaScript-Overhead erfassen können.

Dieses Ranking vergleicht die wichtigsten Open-Source-Tools, Generatoren und Spezifikationen für `llms.txt`.

## Kurzbeschreibung je Tool

### 1. claude-seo
- **Fokus:** Direkte Entwickler-Integration.
- **Nutzen für AEO:** Als Skill in Claude Code integriert, auditiert `claude-seo` Webseiten lokal auf Auffindbarkeit, Struktur und Agent-Tauglichkeit, noch bevor Code committed wird.
- **Repository:** [github.com/AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo)

### 2. OpenGSO
- **Fokus:** Automatisiertes Scoring und Generierung.
- **Nutzen für AEO:** Analysiert Webseiten mit einem Score von 0 bis 100 und erzeugt die erforderlichen Indexdateien (`llms.txt`, `robots.txt`, Sitemap) schlüsselfertig.
- **Repository:** [github.com/sherwinvishesh/OpenGSO](https://github.com/sherwinvishesh/OpenGSO)

### 3. llms.txt-Spezifikation (AnswerDotAI)
- **Fokus:** Offizieller Standard.
- **Nutzen für AEO:** Definiert Syntax, Abschnitte (`# Titel`, `> Zusammenfassung`, optionale Vertiefungen) und Formatierungsregeln für maschinenlesbare Dateien.
- **Repository:** [github.com/AnswerDotAI/llms-txt](https://github.com/AnswerDotAI/llms-txt)

### 4. vitepress-plugin-llms und starlight-llms-txt
- **Fokus:** SSG-Plugins.
- **Nutzen für AEO:** Erstellen beim regulären Build-Prozess von VitePress oder Astro Starlight standardkonforme `llms.txt`-Dateien ohne manuelle Pflege.
- **Repositories:** [github.com/okineadev/vitepress-plugin-llms](https://github.com/okineadev/vitepress-plugin-llms) und [github.com/delucis/starlight-llms-txt](https://github.com/delucis/starlight-llms-txt)

### 5. llms-txt-hub
- **Fokus:** Verzeichnis und Best Practices.
- **Nutzen für AEO:** Dient als Inspirationsquelle, um zu analysieren, wie andere Vorreiter ihre `llms.txt` strukturieren. Hinweis: Lizenzfeld weist `NOASSERTION` aus (nicht als gesicherte Open-Source-Lizenz behandeln).
- **Repository:** [github.com/thedaviddias/llms-txt-hub](https://github.com/thedaviddias/llms-txt-hub)

## Für wen welches Tool?

- **Grundlagen verstehen:** Lesen Sie zuerst die **[llms.txt-Spezifikation](https://github.com/AnswerDotAI/llms-txt)**, um den syntaktischen Aufbau zu beherrschen.
- **Für VitePress oder Astro:** Installieren Sie **[vitepress-plugin-llms](https://github.com/okineadev/vitepress-plugin-llms)** bzw. **[starlight-llms-txt](https://github.com/delucis/starlight-llms-txt)** für automatische Builds.
- **Für Gesamtaudits und Dateierzeugung:** Nutzen Sie **[OpenGSO](https://github.com/sherwinvishesh/OpenGSO)** für Score und konsistente Ausgabedateien.
- **Für Claude Code Nutzer:** Setzen Sie **[claude-seo](https://github.com/AgriciDaniel/claude-seo)** als interaktiven Prüf-Skill in Ihrer IDE ein.
- **Zur Recherche:** Verwenden Sie **[llms-txt-hub](https://github.com/thedaviddias/llms-txt-hub)** als Nachschlagewerk, nicht zur Erzeugung.
