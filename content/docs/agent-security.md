Agent Security is the defensive dimension of Agent Engine Optimization (AEO). The fundamental objective is clear: **legitimate AI agents must be able to act on your website, while malicious or attacking agents must be reliably blocked.**

Agent Security is not an abstract cybersecurity discipline or general IT audit. It focuses specifically on the interaction boundary where autonomous models, browser agents, and execution protocols (such as MCP and Web Bot Auth) interact with web applications, APIs, and commerce platforms.

> **Research Status:** November 22, 2026. All cited metrics, post dates (Europe/Berlin), and provider statements reflect the verified research baseline.

## The Six Core Areas of Agent Security

To secure your digital infrastructure for agentic workflows, Agent Security is structured into six dedicated disciplines:

1. **[Agent Access and Identity](/docs/agent-security-agent-access-and-identity/)**  
   Recognizing and granting access to cryptographically signed agents (such as ChatGPT Dots via RFC 9421 and Cloudflare Personal Agents) while assigning dedicated agent identities rather than shared employee credentials.

2. **[Attacks by AI Agents](/docs/agent-security-attacks-by-ai-agents/)**  
   Understanding the threat posture of autonomous offensive frameworks like ARTEX, monitoring initial access vectors (`/.env`, `/.git/config`), and detecting credential stuffing that impersonates verified agents.

3. **[Prompt Injection and Manipulated Content](/docs/agent-security-prompt-injection-and-manipulated-content/)**  
   Protecting the agent read layer against indirect prompt injections, hidden text (Black-Hat GEO), and supply chain risks in tool descriptions (MCP Tool Poisoning).

4. **[Secure Interfaces: APIs, MCP, and WebMCP](/docs/agent-security-secure-interfaces/)**  
   Enforcing strict boundaries: MCP is an integration mechanism, not a security authorization layer. Implementing DNS rebinding defense, Origin validation, schema verification, and out-of-band human-in-the-loop approvals.

5. **[Agentic Commerce and Fraud Prevention](/docs/agent-security-agentic-commerce-and-fraud-prevention/)**  
   Distinguishing legitimate agent purchases (e.g., via ChatGPT Wallet or Visa Agentic Ready) from automated fraud, binding device signals to cloud-browser sessions (Know Your Human), and addressing chargeback liabilities.

6. **[Secure Development in the AI Era](/docs/agent-security-secure-development/)**  
   Preventing secret leakage through AI coding assistants (such as unencrypted tokens in project configurations), isolating test environments, and defending against device-code phishing.
