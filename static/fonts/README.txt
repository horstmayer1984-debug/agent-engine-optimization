Self-hosted webfonts
====================

These files replace the previous Google Fonts CDN request.

Families and files
------------------
- Fraunces (variable, weights 400-600): fraunces-latin.woff2, fraunces-latin-ext.woff2
- Inter (variable, weights 400-600): inter-latin.woff2, inter-latin-ext.woff2
- IBM Plex Mono (500 and 600): ibm-plex-mono-500-*.woff2, ibm-plex-mono-600-*.woff2

Source
------
Downloaded from the Google Fonts CSS API (latin and latin-ext subsets) on 2026-11-19.
